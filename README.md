## 2.0.0-alpha.30 — 기본곡 보관함(클래식 27곡) · 악보 전체 화면 보기

- **파일 → 기본곡 보관함 · 클래식**: 야마하 P-70 내장 50곡 중 27곡을 오른손·왼손 트랙으로 넣음(재생·악보·편집·제목 찾기 모두 적용). 음표 데이터는 Mutopia Project의 퍼블릭 도메인/CC BY-SA LilyPond 악보를 LilyPond 2.25로 MIDI 변환해 추출(`app/library/*.json`, 출처·라이선스는 `app/LIBRARY_CREDITS.md`). 나머지 23곡은 접근 가능한 퍼블릭 도메인 악보가 없어 미수록.
- **악보·편집 → 악보 전체 화면 보기**: 세로 화면 1쪽, 가로(900px 이상) 2쪽. 화면 왼쪽/오른쪽 터치·스와이프·←→ 키로 넘김. 트랙·손 구분·최소 음표 선택.
- 제목 찾기 ①에 기본곡 27곡의 실제 멜로디 지문이 포함됨(손으로 적은 클래식 4곡은 삭제).
- 서비스워커가 기본곡 파일을 미리 캐시해 오프라인에서도 동작.
검증: 저장소 테스트·SW 시뮬레이션 통과, 실제 빌드 후 Chromium에서 새 곡 → 기본곡 ‘엘리제를 위하여’ 추가(517+388음, 빠르기·제목 반영) → 제목 찾기 100% → 전체 화면 악보 9쪽, 가로 2쪽/세로 1쪽 전환·탭 넘김·Esc 닫기 확인. 실기기 Safari 미확인.

메뉴 **악보·편집 → 곡 제목 찾기** (파일 메뉴에도 같은 항목). 선택한 트랙의 멜로디로 제목을 찾습니다.

구현: `app/title-finder.js`(추가 스크립트, 기존 엔진 전역만 사용), `tools/build_site.py`(스크립트 삽입), `app/sw.js`(캐시 목록), `app/next-boot.js`(메뉴 항목 2개). 녹음·채보·저장 로직 변경 없음. 원본 고정 커밋 변경 없음.

## 2.0.0-alpha.5 — ‘새 화면 시안’을 실제 기본 화면으로 연결

`/preview/`에 있던 승인된 시안의 HTML 구조·레이아웃·색상 규칙을 기본 화면에 사용합니다. 시안의 예제 음표, 가짜 녹음/분석, 별도 시연용 저장소/합성음 코드는 실행하지 않습니다. 현재 버전 2의 실제 프로젝트와 원래 녹음·분석·저장·메트로놈·악보 기능에 연결합니다.

이전 alpha.4 메인 화면은 사용자의 요청으로 별도 **버전 1 저장소**에 배정했습니다. 버전 2의 루트 페이지는 이제 승인된 시안 디자인을 기본으로 사용합니다.

### 유지한 것
- 기존 V2 곡 DB `piano-studio-next-v2`와 원음 데이터. V1의 `home-piano-studio`로 복사하거나 이동하지 않습니다.
- 녹음, AI/기존 분석, MIDI 입력, 원음 듣기/파일 저장, 트랙·악기·솔로·음소거.
- `도도솔솔` 붙여쓰기, 음표 편집, 되돌리기, 박자·양손·코드·반주·전주·후주 도구.
- 악보 PNG/SVG/MusicXML/인쇄, MIDI/곡 JSON 내보내기·불러오기.
- 독립 메트로놈, 시스템/다크/일반 테마, 버전 1 전환 버튼.

### 화면 사용
- 하단: 녹음 · 악보 생성 · 재생 · 메트로놈.
- `…` 메뉴: 타이핑, 곡·파일, 녹음·AI, 트랙·악기, 박자·편곡, 기존 편집 도구.
- 집중 편집: 실제 음표를 선택·이동·길이 변경·손 배정. 변경은 실제 곡에 반영됩니다.
- **닫기**는 수정 내용을 버리지 않습니다. **되돌리기**로 취소하고 **완료**는 저장 성공을 확인한 뒤 닫습니다. 저장이 실패하면 편집창을 유지합니다.
- 시안의 ‘양손’은 지정된 손 정보 또는 C4 기준 표시입니다. 자동 양손 분리 알고리즘 개선 완료를 의미하지 않습니다.
- 배속·손별 연습 재생은 음표 데이터를 변경하지 않습니다. 원음 트랙은 손별 분리가 불가능하며, 원음의 배속에는 음높이 변화가 있습니다.
- 원래 화면 확인: 현재 주소에 `?ui=classic` 추가. 같은 버전 2의 같은 곡 보관함을 사용합니다.

### 설치
이 업데이트의 `app/next-boot.js`, `tools/build_site.py`, `VERSION`, `README.md`를 같은 경로에 교체합니다. 기존 `index.html`, AI 번들, 다른 `app`/`tools` 파일을 삭제하지 않습니다. 기존 Pages Actions 설정은 그대로 사용합니다.

### 검증 범위
로컬 Chromium의 여러 뷰포트, 실제 원본에서 발췌한 타이핑/편집 코드, 모사된 원본 화면·저장·음성·악보 환경으로 연결과 보존을 검사했습니다. 저장 실패, 회전, 테마, 숨김 상태의 이전 설정도 검사합니다. 원본 전체 앱·실제 AI/마이크·실제 IndexedDB/PWA·실기기 Safari에 대한 종단간 검증은 아닙니다. 인식률/녹음 음량/양손 분리/편곡 알고리즘을 개선한 버전은 아닙니다.
