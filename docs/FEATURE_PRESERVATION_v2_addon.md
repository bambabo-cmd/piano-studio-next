# 기존 기능 보존 대조표

검토 기준: 2026-09-28 공개된 bambabo-cmd/piano-studio main의 index.html과 sw.js.

```text
https://github.com/bambabo-cmd/piano-studio
https://raw.githubusercontent.com/bambabo-cmd/piano-studio/main/index.html
https://raw.githubusercontent.com/bambabo-cmd/piano-studio/main/sw.js
```

이 표는 원본 코드에서 확인한 기능의 보존 기준입니다. 모든 기능의 품질/실기기 동작을 새로 검증했다는 뜻이 아닙니다. 미래에 원본 버전이 달라지면 적용 도구의 구조 검사를 먼저 실행하세요.

| 기능 묶음 | 보존할 기존 기능 | 이번 원본용 추가 도구의 처리 |
|---|---|---|
| 입력·녹음 | 마이크/MIDI, 재생하며 녹음, 원음 보관, 자동 MP3 저장/폴더, 파일 불러오기 | 기존 DOM·이벤트·녹음 경로 그대로. 하단 녹음 버튼만 기존 recBtn 호출 |
| 분석 | AI/자체 분석, 단음 입력 관련 설정, 음량 균일화 등 | 파서·모델·설정·분석 코드를 바꾸지 않음 |
| 재생 | 재생/정지, 처음, BPM, 전체 음량, 재생 위치 | 하단 재생 바로가기는 기존 playBtn 호출. 원래 설정 유지 |
| 메트로놈 | 독립 실행, BPM, 박자, 세분화, 소리, 음량, 탭, 곡 BPM 가져오기/적용 | 기존 mpOpen/mpStart/mpClose를 호출. 원래 저장 설정을 먼저 불러옴 |
| 녹음 보조 박자 | 녹음/재생용 메트로놈, 첫 박 강조, 카운트인 | 독립 메트로놈과 별도 기능으로 유지. 제거/통합하지 않음 |
| 트랙 | 이름, 악기, 음량, 솔로·음소거, 삭제, 원음 듣기 | 기존 트랙 UI와 데이터 모델 유지 |
| 음표 입력·편집 | 빈 트랙, 타이핑 음표/쉼표, 선택·그리기·삭제·범위, 스냅, 길이, 옥타브, 손 교체, 확대, 따라가기 | 기존 편집 UI와 코드를 유지. 독립 시안으로 대체하지 않음 |
| 실행 취소 | 되돌리기·다시 실행, 선택·삭제 | 기존 동작 유지 |
| 시간 정리 | 박자 찾기, 자동 정렬, 탭 정렬, 구간 늘이기/맞추기 | 기존 알고리즘 유지 |
| 음·손 정리 | 음 보정 제안, 자동 양손 나누기, 수동 손 교체 | 기존 기능 유지. 분리 정확도 개선은 아직 별도 작업 |
| 편곡 | 코드 찾기, 왼손 A/B/C 반주, 전주·후주 | 기존 처리 그대로. 새 편곡 알고리즘을 구현한 것이 아님 |
| 출력 악기 | 기타 등을 포함한 기존 합성 악기 선택 | 기존 악기 목록 유지. 기타 전용 운지표·카포·스트로크 악보가 완성됐다는 뜻은 아님 |
| 악보 | 트랙/제목, 최소 음 길이, 레가토, 손/고정 음역 기준, 악보 창 | 기존 shOpen으로 원래 악보 창 호출 |
| 내보내기 | PNG, SVG, MusicXML, 인쇄/PDF, MIDI, JSON(원음 포함/제외) | 기존 버튼·이벤트·변환 코드 유지 |
| 곡 관리 | 새 곡, 선택, 이름 변경, 삭제, 로컬 저장·복원 | 기존 저장소 키/DB·프로젝트 포맷 유지 |
| PWA/캐시 | 기존 정적 자원과 서비스 워커 | 파일 복사. 인식 가능한 캐시 버전 문자열만 변경 |

## 호출 연결

- 녹음: `recBtn`
- 악보: `shOpen`
- 재생: `playBtn`
- 독립 메트로놈: `mpOpen`, `mpStart`, `mpClose`, `metroPanel`
- 원본 메트로놈 상태: 버튼 `running` 클래스·aria/텍스트 변화를 관찰
- 새 테마: `PianoTheme`와 별도 `piano-studio-theme-v2` 저장 키

새 코드는 `ps-tools-*`, `ps-theme-select`, `ps-metro-settings` 전용 UI ID를 사용하며 기존 버튼이나 핸들러를 대체하지 않습니다. DOM 보존·핸들러 동일성 검사는 테스트용 모사 화면에서 수행했습니다.

## 아직 별개인 일

1. 새 반응형 시안 전체에 원본 모든 기능을 이식하는 작업.
2. 입력 음량 개선, AI 준비 시간, 불필요 음표 정리, 정확한 양손/성부 분리.
3. 기타 코드·운지·카포·스트로크 등을 갖춘 별도 출력의 완성도 검증/구현.

원본 기능을 보존했다는 이유만으로 위 품질 문제가 해결됐다고 판단하지 않습니다.
