## 검사 구분

현재 alpha.3 검사 개수와 범위는 `TYPING_UPDATE_ALPHA3.md`를 확인합니다. `TEST_REPORT.md`는 alpha.2 과거 기록입니다. 빌더는 합성 입력, 타이핑은 실제 파서 발췌 및 모의 앱 연결, 저장/캐시는 모형 기반 검사입니다. 실제 원음·AI·전체 악보·실기기 검사로 해석하지 않습니다.

`docs/FEATURE_PRESERVATION_v2_addon.md`는 이전 추가 도구의 기능 목록이다. 거기에 적힌 저장 키/DB 유지 설명은 기존 앱에 추가하던 이전 도구 기준이다. **이번 별도 저장소에서는 이 문서와 README가 우선**이며, DB/설정/서비스 워커를 명시적으로 분리했다. 녹음·AI·재생 로직은 유지한다. alpha.3에서는 타이핑의 토큰 분리와 안내 문구만 명시적으로 개선한다.
