## 중요한 한계

- 실제 원본 전체 파일을 여기서 내려받아 빌드하거나 실행하지 못했습니다. 웹으로 공개 코드와 기준 커밋을 확인했고, GitHub Actions가 고정 원본을 가져와 빌드하도록 구성했습니다.
- 브라우저 네트워크 탐색은 관리자 정책으로 차단되었습니다. 실제 IndexedDB/네트워크 테스트 대신 set_content와 **모의 저장 트랜잭션**을 사용했습니다. 실제 IndexedDB 검증으로 표현하면 안 됩니다.
- 사용자 GitHub의 빌드/배포 성공, 실제 iPhone/iPad Safari, 마이크/MIDI, AI 인식률, 오프라인 PWA 실행은 미검증입니다.
- 새 반응형 UI 전체와 원본 엔진은 아직 통합되지 않았습니다. `/preview/`는 분리된 시안입니다.
- 동봉 스크린샷은 명확히 표시된 전환 버튼 **검사용 화면**입니다. 실제 원본 앱 전체 실행 스크린샷이 아닙니다.

기록: `UNIT_TESTS.txt`, `LOCAL_BROWSER_CHECKS.json`, `VERSION_SWITCH_BROWSER_CHECKS.json`, `SW_SIMULATION_CHECKS.txt`, `JS_SYNTAX_CHECKS.txt`.
버전 1 자체 로그는 별도 묶음의 `version-switch/`에 있습니다.
