선택한 테마를 기억합니다. 시스템 기본은 기기의 화면 모드를 따릅니다.

녹음·악보·재생을 먼저 보여 주고, 덜 사용하는 기능은 이곳에서 엽니다. 이 시안은 마이크에 접근하거나 AI 모델을 내려받지 않습니다.

기존 앱 기능 보존 범위

이 파일은 UI 시안입니다. 아래 기능을 삭제하는 대체 앱이 아닙니다. 동봉한 original_addon은 원본 코드를 유지하고 빠른 메트로놈·테마만 덧붙입니다.

  • 마이크/MIDI 녹음, 원음 보관·듣기·MP3, 파일 불러오기
  • 트랙·악기·음량·솔로·음소거, 빈 트랙·타이핑 입력
  • 선택·그리기·삭제·구간·음 길이·옥타브·손 바꾸기, 되돌리기
  • 박자 찾기·탭 정렬·구간 늘이기·음 보정·양손 나누기
  • 코드 찾기·왼손 반주·전주·후주, 분석 설정
  • 곡 저장·복원, MIDI·PNG·SVG·MusicXML·인쇄/PDF
  • 독립 메트로놈과 녹음/재생용 메트로놈·카운트인

기능 보존과 인식률·양손 분리·편곡 품질 개선은 별도입니다.
